# TravelX - Online Bus Booking System

TravelX is a web-based bus booking system that allows customers to search buses, select seats, book tickets, and manage their bookings. The platform also provides Agent and Admin modules for bus management and system administration.

---

## Features

### Customer
- User Registration & Login
- Search Buses
- View Available Trips
- Seat Selection
- Passenger Details Entry
- Ticket Booking
- Payment Integration
- Booking History
- Ticket Cancellation
- Feedback & Ratings
- Profile Management

### Agent
- Agent Registration & Login
- Add New Buses
- Manage Trips & Schedules
- Set Route Pricing
- View Passenger Bookings
- Track Bus Approval Status
- Profile Management

### Admin
- Secure Login
- Manage Customers
- Approve/Reject Buses
- Monitor Feedback
- System Administration

---

## System Modules

### Customer Module
Customers can search for buses based on source, destination, and date. After selecting seats and entering passenger details, they can complete the booking process and manage their tickets.

### Agent Module
Agents can register their travel business, add buses, create trips, and monitor bookings for their buses.

### Admin Module
Admin verifies buses submitted by agents and manages users to maintain system quality and reliability.
